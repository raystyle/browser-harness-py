# G001 文档标准细则：命名写作规范

> 落点：`docs\guide\`。命名与编号规则的权威源；新文档按此命名并登记进 `INDEX.md`。

## 命名

- 方案：`docs\proven\PNNNN-短名.md`（P 后 4 位，短名用 `-` 连接）
- 研究：`docs\research\SNNN-短名.md`（3 位）
- 参考：`docs\references\RNNN-短名.md`（3 位）
- 元规范：`docs\guide\GNNN-短名.md`（3 位）
- 错误：`docs\mistakes\M1xx-分类.md`（分类文件），行级 `M0xx` 全局递增
- 日记：`docs\diary\YYYY-MM-DD-短名.md`

## 编号

- 各前缀独立递增，接当前最大号；编号不复用。
- 退役编号留痕，不复用。

## 写作

- 中文为主，结论可溯源。
- 只增不改历史行；错误修正追加「正确处理」，不删历史。
